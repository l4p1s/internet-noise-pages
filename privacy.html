INTERNET NOISE

プライバシーポリシー

最終更新日：2026 年 11 月 24 日

「Internet Noise」（以下「本アプリ」）での情報の扱いを説明します。本アプリは運営者が個人で運営し、運営者本人だけが使います。

1. Google アカウントから得る情報

本アプリは YouTube API サービスを使います。運営者が自分のアカウントで許可すると、次の情報を受け取ります。

  • アクセストークンとリフレッシュトークン
  • つながったチャンネルの名前などの基本情報
  • アップロードした動画の ID

2. 使い道

運営者のチャンネルへの動画のアップロードと、つながった先のチャンネルの確認にだけ使います。広告、分析、機械学習には使いません。

3. 保存と共有

トークンは運営者が管理するサーバに、本人だけが読める設定で保存します。投稿した動画の ID と URL も、二重投稿を防ぐために保存します。投稿の報告として、動画の題名と URL を運営者自身の Discord に送ることがあります。それ以外に、Google から受け取った情報を第三者に販売、提供することはありません。

4. 取り消しと削除

許可は Google アカウントの接続の管理ページからいつでも取り消せます。取り消したあと、保存したトークンは削除します。

5. 動画のもとになる記録

公開の通信から残すのは、件数、データ量、形式の統計、緯度経度 1 度（約 111 km）に丸めた位置、タイムゾーン名、編集のあった Wikimedia のサイト名などです。通信の本文は保存しません。

6. 関連する規約

YouTube の利用には YouTube 利用規約と Google プライバシーポリシーが適用されます。本アプリによる Google API から受け取った情報の使用は、Google API サービスのユーザーデータに関するポリシー（限定的な使用の要件を含む）に従います。

7. 連絡先
