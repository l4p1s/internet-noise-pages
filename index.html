Internet Noise

Internet Noise は、インターネットを流れる公開の通信を録音し、音と映像にする個人のアプリです。できた動画を、運営者本人の YouTube チャンネル「インターネットノイズ」などに投稿します。

できること

  • 公開 MQTT ブローカーと、Wikimedia の編集ストリームの流量を記録します。
  • 記録から 45 秒の音と映像を作ります。
  • YouTube Data API を使い、運営者のチャンネルへ動画をアップロードします。

使う人

運営者本人だけが使います。一般の方のアカウント登録やログインは受け付けていません。
